# Maharashtra State CET CAP Cutoff Dataset

This repository contains the complete data engineering and cleaning pipeline for the **Maharashtra State Common Entrance Test (CET) CAP Cutoff records for Engineering Colleges**, spanning from the academic year **2022-2023** to **2026-2027**.

This dataset is designed to be highly robust, surgically verified, and 100% ready for Machine Learning tasks such as percentile prediction and admission probability modeling.

---

## 🏗️ Data Architecture

The data directory is structured to preserve data integrity and prevent cross-contamination between raw extraction and final ML datasets.

```text
data/
│
├── raw/
│   ├── 2022-2023/...
│   ├── 2023-2024/...
│   └── master_cap_cutoff_raw.csv        # Consolidated raw dataset
│
├── intermediate/
│   └── master_cap_cutoff_cleaning.csv   # Working file for validation
│
├── final/
│   └── master_cap_cutoff_final.csv      # The ML-Ready Final Dataset (~397k records)
│
└── quarantine/                          # Segregated unrecoverable data
    ├── invalid_category.csv
    ├── missing_branch.csv
    ├── invalid_rank.csv
    └── potential_duplicates.csv
```

## 🚀 The Data Pipeline

The pipeline consists of three core Python scripts executed sequentially to transform raw, noisy PDF extractions into a pristine dataset.

### 1. Standardization (`src/data/standardize_data.py`)
Takes the raw `.csv` and `.xlsx` files generated by the PDF parser, normalizes the columns, standardizes the file naming structure, and consolidates everything into a single `master_cap_cutoff_raw.csv` containing over 405,000 records.

### 2. Cleaning & Recovery (`src/data/clean_data.py`)
This script contains the core business logic for repairing parser-damaged records without resorting to artificial statistical imputation.
- **Source-Level Category Recovery**: Uses group-limited `ffill()` and `bfill()` on `[college, branch, seat_section]` boundaries to successfully recover over 12,900 missing categories that were overwritten by PDF headers.
- **Branch Code Mapping**: Explicitly maps standard branch codes to valid branch names where the raw parser missed the branch header.
- **Quarantine Engine**: Segregates mathematically broken or incomplete rows (e.g., `Rank <= 0`, unrecoverable text chunks) into specific files in the `/quarantine` folder, ensuring the final dataset remains untainted.

### 3. Validation (`src/data/validate_data.py`)
Generates the **Master Data Quality Report** across 17 different validation criteria including:
- Year and CAP Round Coverage
- Exact Duplicate Checks
- Branch and College Code validation
- Rank and Percentile bounds checking
- Missing Value Analysis

## 📊 Dataset Status

As of the latest pipeline execution, the final ML dataset (`master_cap_cutoff_final.csv`) contains **397,152** pristine records with **0 missing values** across all critical columns (Rank, Percentile, Category, Branch, College).

All records represent authentic admission boundaries published by the state, with no data fabricated through mean/mode imputation.
